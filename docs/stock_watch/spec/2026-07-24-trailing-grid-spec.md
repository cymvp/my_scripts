# 追踪网格（方案 A）— 设计文档（Spec）

- 日期：2026-07-24
- 模块：stock_watch / trade_assist（升级 GridEngine + RiskGuard）
- 状态：回测通过，实现中
- 回测结论（21天15分钟K，扣费，见 backtest_trailing.py）：组4(追踪VWAP+停手+2%熔断) 日均 4.02%、最差日 -5739，双双优于组2(现状固定网格) 的 1.30% / -9662。**注意：4.02% 绝对值是 bar 级回测的前视幻觉、无滑点，仅组间相对可信；实盘规划以"优于现状固定网格 + 最差日约 -5% 级"为准。**
- 动机：固定昨收中轴的网格罩不住偏离区——跳空低开时买档悬空、上涨趋势时买档钉在低位够不着回调。两者同一病根：中轴不动。追踪网格让中枢随价格移动，网格始终罩在现价附近。

## 1. 核心变化：中枢改为「价格驱动」跟随（2026-07-24 二次修订）

- 中枢初始 = 昨收；此后**当现价偏离中枢达 2 档（1.2%）就把中枢移到现价**（recenter_steps=2）。
- 舍弃了原「VWAP 驱动」——VWAP 是全天累计均价、太慢太粘，实盘中价格跌 2% 中枢一整天没跟下来，网格罩在价格上方、卖档够不着（实盘 2026-07-24 暴露）。
- 回测（21天15分钟K，扣费）：价格驱动2档 日均 4.94% / 盈利18天/21 / 最差日 -3017，全面优于 VWAP驱动 的 3.86% / 15 / -5739，也优于固定昨收 1.31% / 12 / -9662。（绝对收益率是 bar 级前视幻觉，仅相对可信。）
- 参数 RECENTER_STEPS 可调：1 档更激进（回测更高但过拟合风险大），3 档更钝。

### 【历史方案，已弃用】原「滚动 VWAP」设计

- 中枢 `center` = 当日 VWAP（累计成交额 ÷ 累计成交量，新浪快照自带）。
- 网格档位实时基于 center 计算：`buy_k = center×(1−step×k)`，`sell_k = center×(1+step×k)`，k∈[1..n]。
- center 随成交上移/下移，整张网格跟着平移——这是"追踪"的含义。

### 滚动的稳定性处理（防止 center 每 tick 微动导致档位抖动、触发混乱）

问题：VWAP 每 tick 都在变，若档位价随之连续漂移，"已触发"记录（按档号索引）会失效。

方案：**按步长离散滚动**。维护一个"锚定 center" `anchor`（网格实际使用的中枢）：
- 初始 anchor = 开盘后第一个有效 VWAP。
- 每 tick 比较实时 VWAP 与 anchor：当 `|VWAP − anchor| ≥ step×anchor`（漂移满一格）时，anchor 跳到 VWAP，**整张网格重算，已触发集合清空**（新价格区间是新战场）。
- 未满一格时 anchor 不动，网格稳定，触发判定照旧。

这样网格是"跳格式"跟随，而非连续滑动：既跟得上趋势，又保持格内的触发稳定。

## 2. 触发与配对（不变）

- 价格下穿买档 → 买信号；上穿卖档 → 卖信号；每档在当前 anchor 周期内只触发一次。
- 配对目标 = 成交价 ± 2×step（买腿向上、卖腿向下），与固定网格一致。
- anchor 跳格重算时，已持有的未配对 T 腿**不受影响**（它们盯的是自己的绝对目标价，独立于网格）。

## 3. 新增风控：日内最大亏损熔断（关键）

追踪网格在单边反转时会套住一批高位买入（T+1 当天平不掉），必须有硬熔断：

- 实时计算当日**浮动+已实现**总亏损：`realized_pnl + Σ(未配对腿的浮亏)`（未配对买腿浮亏 = (现价−买价)×qty，卖腿反之）。
- 亏损超过 **资金池 × 2%** → 触发熔断：停止一切新信号，只提示"熔断：建议平掉未配对 T 腿控损"，当日不再开新 T。
- 熔断阈值 2% 是初值，回测校准。

## 4. 保留的既有风控

- 趋势停手（上行停卖档 / 下行停买档）——但追踪网格下"下行停买"要重新评估：中枢下移后买档也下移，接的是相对低点而非绝对下跌，可能不必再一刀停买。**回测对比"下行停买 开/关"两种**再定。
- 涨跌停 1% 静默、14:45 停开新 T、单日成交≤底仓30%——不变。

## 6. 若实现（TDD 范围）

- `GridEngine`：加 `roll(vwap)` 方法（判是否跳格、重算档位、清触发集）；`center`/`anchor` 状态。
- `RiskGuard` 或 `TradeBook`：加 `floating_pnl(current_price, open_legs)` 与熔断判定。
- 单测：跳格重算、跳格后触发、未配对腿跨跳格不丢、熔断触发与解除、浮亏计算。
- GUI：信号栏加熔断状态显示；其余不变（多股架构已就位）。

## 7. 诚实边界

- 追踪网格是"顺势的均值回归"，不是趋势跟随——它在上涨里买回调、不追高；单边极端行情仍会亏（靠熔断+限额把尾部砍掉）。
- 不承诺提高胜率，只解决"网格罩不住偏离区"的结构缺陷。最终以回测数据说话。
