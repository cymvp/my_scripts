# 做 T 助手（trade assist）— 设计文档（Spec）

- 日期：2026-07-24
- 模块：stock_watch / trade_assist
- 状态：已回测，实现中
- 前提约束：A 股 T+1，日内差价唯一形态是**底仓做 T**；用户手动下单，程序只给信号并记账。

## 1. 目标与非目标

**做**：
- 对单只目标股（默认中际旭创 sz300308）做网格化做 T 信号：触档给出 限价 + 数量 的买/卖提示
- 三路提醒：悬浮窗信号栏 + macOS 通知/提示音 + Slack
- 用户回报成交后实时记账：档位状态、可用底仓/资金、当日做 T 盈亏
- 指标风控：单边趋势日自动停手逆势信号

**不做（YAGNI + 诚实）**：
- 不做自动下单、不接券商 API
- 不做多股票同时做 T（先验证一只）
- 不承诺"每天 1-3%"：目标是震荡日赚参与资金的 0.5-1.5%，趋势日停手

## 2. 网格引擎

- 中轴 = **昨收价**，档距 `step`（默认 0.6%——21 天 15 分钟线回测：0.6%+趋势停手 日均+1.26%/手、最差日-9.7k；0.9% 日均+0.55%；≥1.2% 亏损），上下各 5 档：
  `level_k = prev_close × (1 + step×k)`，k ∈ [-5..-1]（买档）∪ [1..5]（卖档）
- 触发：最新价**下穿**买档（前一笔 > 档位 ≥ 当前）→ 买入信号，限价 = 档位价；**上穿**卖档同理
- **每档每日最多触发一次**；已触发未回报成交的信号 5 分钟后自动过期（可再触发）
- 配对：k 档买入的 T 仓，目标卖出价 = 买价 × (1 + 2×step)；先卖后买回同理。程序跟踪未配对 T 腿并在状态里显示
- 千元股 1 手≈10.7 万：布档数 = min(5, 资金池÷(现价×100))，每档量 = 总手数÷档数（取整百）；资金池不足 1 手时禁用并提示

## 3. 风控（信号静默条件，优先级从高到低）

1. 距涨停/跌停 < 1%：全部静默
2. **趋势停手**：**上行趋势（价 > VWAP×1.015 且 VWAP 连续上行）→ 暂停卖出档**（防高卖踏空）；**下行趋势（价 < VWAP×0.985 且 VWAP 连续下行）→ 暂停买入档**（防接飞刀）。"连续"= 最近 3 个取样点（间隔≥3 分钟）单调
3. 放量创日内新低（最新 5 分钟量 > 当日 5 分钟均量×2 且价创新低）→ 暂停买入
4. 14:45 后不触发新档；只提示未配对 T 腿的收尾
5. 单日做 T 累计成交量 ≤ 底仓 × 30%

VWAP = 快照累计成交额 ÷ 累计成交量（新浪快照自带，无需分钟线）。

## 4. 记账（TradeBook）

- 配置与状态存 `~/.stock_watch_trade.json`（600 权限，**绝不进公开仓库**）：
  `{stock, base_shares(底仓), cash(可用资金), t_pool(T资金池), step, fills:[{ts,side,qty,price}], triggered_levels:[...], date}`
- 跨日：日期变更时清空 triggered_levels 与当日 fills（归档到 history），底仓/资金延续
- 成交回报（GUI 弹窗输入 qty/price）后：更新可用资金/可卖底仓、检查配对、算已实现盈亏（含费用：佣金 0.025% 双边 + 印花税 0.05% 卖出 + 过户费忽略）
- 约束校验：卖出 ≤ 当前可卖（底仓 + 已买回），买入金额 ≤ 可用资金；违反则拒绝记账并提示

## 5. GUI 集成（stock_watch.py）

- 悬浮窗底部新增**信号栏**（启用做 T 时显示）：常态显示 `T: 就绪 距上档+0.4% 距下档-0.5% 当日盈亏+123`
- 出信号：信号栏红/绿高亮 `▼买300@985.5` + `[成交][忽略]` 两个小按钮；同时 osascript 通知 + `afplay` 提示音 + Slack 推送
- `[成交]` → simpledialog 输入 `数量 价格`（预填建议值）；`[忽略]` → 信号关闭、该档今日不再触发
- 首次启用：菜单（右键时间）新增"做 T 设置"，弹窗输入底仓/可用资金/T 资金池
- 收盘后（15:00）信号栏显示当日总结并推送 Slack 日报

## 6. 模块与文件

- `trade_assist.py`（新，与 stock_watch 同目录）：`GridEngine`、`TradeBook`、`RiskGuard` 纯逻辑 + 配置读写。不 import tkinter，可独立单测
- `stock_watch.py`：解析函数增加 open/high/low/vol/amount 字段（向后兼容）；刷新循环喂 quote 给引擎；信号栏 UI
- `backtest_grid.py`（新，一次性工具）：拉可得的 5 分钟 K 回测档距参数

## 7. 测试用例表（TDD 依据）

| 场景 | 输入 | 期望 |
|------|------|------|
| 档位生成 | prev_close=1000, step=0.9% | 买档 [991,982.9,...]，卖档 [1009,1018.1,...] |
| 下穿触发 | 前一笔 992 → 当前 990.5 | 触发 -1 档买入信号，限价 991 |
| 同档不重复 | 再次穿越同档 | 无信号 |
| 信号过期 | 触发 5 分钟未回报 | 档位恢复可触发 |
| 配对目标 | -1 档买入 991 成交 | 生成目标卖出 991×1.018 |
| 建议量 | t_pool=100000, 价 991 | 只布 1 档、100 股 |
| 建议量-足额 | t_pool=550000, 价 991 | 5 档、每档 100 股 |
| 趋势停手-上 | 价 > VWAP×1.015 且 VWAP 上行 | 卖出档静默，买入档正常 |
| 趋势停手-下 | 价 < VWAP×0.985 且 VWAP 下行 | 买入档静默 |
| 尾盘静默 | 14:46 触档 | 无新信号 |
| 卖出超底仓 | 可卖 300，回报卖 400 | 拒绝记账并报错 |
| 买入超资金 | 可用 5 万，回报买 10 万 | 拒绝 |
| 单日限额 | 累计成交达底仓 30% | 后续信号静默 |
| 盈亏计算 | 买 300@991 卖 300@1009 | 已实现盈亏 = (1009-991)×300 − 费用 |
| 跨日重置 | date 变更 | triggered/当日 fills 清空，底仓资金延续 |
| 配置往返 | save 后 load | 相同状态 |
