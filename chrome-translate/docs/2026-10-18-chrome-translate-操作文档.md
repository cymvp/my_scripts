# chrome-translate 操作文档

插件作用：打开一篇英文文章，点一下工具栏图标，每个正文段落下方出现中文译文，原文保留。翻译由个人 LLM Router 完成，默认模型 `cuiyang/gpt-6-luna`。

## 1. 安装（只做一次）

1. Chrome 地址栏输入 `chrome://extensions`，打开右上角「开发者模式」。
2. 点「加载已解压的扩展程序」，选择目录 `~/projects/my_scripts/chrome-translate/`。
3. 点工具栏的拼图图标，把「Article Translator」固定到工具栏。

## 2. 配置 API key（只做一次）

1. 第一次点插件图标会自动打开设置页，顶部提示「请先填写 API key」。
2. 从 `~/.config/llm-router/.env` 里复制 `LLM_API_KEY` 的值，粘贴到「API key」，点保存。
3. Endpoint 和模型已预填，一般不用改。改 endpoint 到别的主机时 Chrome 会弹一次权限申请，点允许。

key 只存在本机 Chrome 里，不会写进仓库。换电脑要重新填一次。

## 3. 日常使用

| 操作 | 结果 |
|---|---|
| 在文章页点图标 | 开始翻译。角标显示百分比，译文按批出现在段落下方 |
| 翻译中再点 | 取消。已出现的译文保留，角标清空 |
| 翻完再点 | 移除全部译文，恢复原页 |

## 4. 角标含义

| 角标 | 含义 | 处理 |
|---|---|---|
| `45%` | 翻译进行中 | 等 |
| 红色 `ERR` | 有批次失败，对应段落下有红字说明原因 | 点两次图标（移除、再翻）重来。连续失败先检查内网是否连通 |
| `N/A` | 当前页面不允许注入脚本（如 `chrome://` 页、Chrome 商店页） | 换页面 |
| `0` | 没找到正文 | 该页面不是文章类页面，插件不适用 |

## 5. 已知限制

- 只能在能访问 `172.24.201.32` 的网络里用。
- 不缓存译文，刷新页面后要重新翻。
- 由前端框架重新渲染的页面偶尔会把译文冲掉，再点两次图标即可。
- 不翻译代码块、导航栏、侧边栏、评论区。

## 6. 更新插件

改过代码后，到 `chrome://extensions` 点插件卡片上的刷新按钮。已打开的页面要刷新一次才会用到新代码。

## 7. 开发与测试

```bash
cd ~/projects/my_scripts/chrome-translate
npm install
npm test
```

设计文档在 `docs/spec/`，实施计划和验收记录在 `docs/tasks/`。
